# Configuration

Learn how to configure the product for your needs.

## Configuration Files

Main configuration is stored in `config.yaml`.

## Basic Settings

```yaml
app:
  name: "My Application"
  port: 8080
  debug: false
```

## Environment Variables

Set these environment variables before running:

- `APP_ENV` - Environment (dev, staging, prod)
- `API_KEY` - Your API key
- `LOG_LEVEL` - Logging level (info, debug, error)
