# macOS Installation

Step-by-step installation guide for macOS.

## Prerequisites

- macOS 10.15 (Catalina) or later
- Admin account access

## Installation Process

1. Download the macOS installer (.dmg file)
2. Open the DMG file
3. Drag the application to Applications folder
4. Launch from Applications

## Security Settings

You may need to allow the app in System Preferences > Security & Privacy.
